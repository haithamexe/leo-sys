    Smart keys

    Hold Ctrl, Alt, Shift or the Windows key and only the keys that do something with it glow, coloured by what they do. leo-sys looks at which of those four is held and at the file name of the program that has focus. It never sees what you type.

    Smart keysWorks while leo-sys drives the keys and no Claude effect or picked colour is showing. On the keyboard's own lighting, the other keys go dark while a modifier is held.
    Light the shortcut keys while a modifier is held
    Glow a program's Ctrl shortcuts while it has focusSoftly, over your key lights. Only for programs with their own map, and not over the keyboard's own lighting.

    Typing speed and heatmap

    Counts only. While this is on, leo-sys asks Windows about 100 times a second which keys are down and counts each key press. It keeps, in memory only, a count for each key and how many typing keys were pressed in each ten-second stretch of the last six minutes. It never keeps which key followed which, the time of any single key press, or any text, and nothing is saved or sent anywhere. The Typing heatmap key light shows each key's relative use as a colour, in this panel's picture of the keyboard too; the counts themselves are never sent here. Switching it off, Reset, or restarting leo-sys wipes it all. It is not a keyboard hook, but security software may still notice a program asking about letter keys.

    Count key pressesOff: nothing is counted and any counts are thrown away. It feeds the Typing speed app and the Typing heatmap key light.

    Taskbar alerts

    When a program flashes its taskbar button (Discord, WhatsApp, a browser tab with a message), the keys flash in its colour and the matrix shows its name. leo-sys is told by Windows that a button flashed and keeps only the program's file name, never the window's title or any message text. It is not a keyboard hook.

    Flash the keys when a program flashes in the taskbarOff: leo-sys does not listen for taskbar flashes at all.

    Screen colours

    Pick Screen colours in the Key lights list above and the keys follow the colours of your screen. Windows shrinks the screen to a 32 × 18 grid of colours about 10 times a second and only that grid is kept, in memory. Nothing is saved or sent anywhere, and the screen is not read at all unless Screen colours is picked. Only the main monitor is read, and some protected video shows as black.

    White balance: if the keys look tinted next to your screen, lower the channel that is too strong (100 leaves it alone).

    Weather and prayer times

    Both are apps for the matrix: pick Weather or Prayer times in the LED matrix list above, or add them to the Rotation. Each has its own switch, and one that is switched off is skipped.

    WeatherFrom Open-Meteo, over the internet. Each request carries your city's coordinates (to about a kilometre), and like any web request the service also sees your internet address. At most one request every 30 minutes, and only while the Weather app is on the matrix or in the rotation (it stops about a minute after). Off: nothing is ever sent.
    FahrenheitOff: Celsius.

    Prayer timesWorked out on your PC from the date and your city. Nothing is sent anywhere. The times follow this PC's time zone.

    Minutes to add to each time (a negative number takes minutes off), to match a timetable you trust.

    Scripts and other programs on this PC can show text or a colour with the leo-sys command, for example when a build finishes. It works only on this PC.
